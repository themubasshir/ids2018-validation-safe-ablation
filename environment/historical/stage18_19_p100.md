# Stage18 and Stage19 P100 Environments

Stage18 records an initial incompatible PyTorch 2.10.0+cu128 state and a
repaired PyTorch 2.10.0+cu126 state with P100 `sm_60` support. Its exact Python
patch version, SciPy and Matplotlib remain unproven.

Stage19 separately proves Python 3.12.13 and PyTorch 2.10.0+cu126 on a Tesla
P100 with CUDA 12.6 and `sm_60`. NumPy, pandas, scikit-learn and SciPy are not
proven for that exact session.

These records are not inherited from Stage15 and are not merged with Stage20.
