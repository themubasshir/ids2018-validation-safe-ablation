# Stage26 CPU Profiling Environment

The historical CPU receipt records Linux/glibc 2.35, Python 3.12.13, four
logical/two physical cores, 31.348 GiB RAM, NumPy 2.0.2, pandas 2.3.3,
scikit-learn 1.6.1, LightGBM 4.6.0, XGBoost 3.2.0, CatBoost 1.2.10 and
PyTorch 2.10.0+cpu.

The measurement protocol is reproducible, but the historical latency, memory
and throughput values are hardware-specific archival evidence. The safe
wrapper never starts a timer or profiler.
